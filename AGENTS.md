# Project working instructions

After each change, verify the result and look for errors before reporting completion.

- Build with `python3 src/build.py`; for Pages also run `python3 scripts/build-pages.py`.
- Exercise changed behavior and related functionality in a real browser.
- For UI changes, check desktop and mobile layouts and JavaScript errors.
- Test with actual local assets; do not treat mocked-image tests as proof that photographs load.
- After deployment, verify the public website if network access permits. Report any blocked checks.
- Clearly distinguish local changes, pushed commits, successful deployment, and verified public behavior.
- Never report the public website updated based only on a local test or successful Git push.
